# Bolo nas Alturas — páginas públicas

Site estático que existe por uma razão: a Google Play exige uma **URL pública** para
a política de privacidade antes de publicar o jogo, e o repositório do jogo é
privado — o GitHub Pages em repositório privado só funciona com plano pago.

Então o código do jogo continua fechado e só esta página fica aberta.

| arquivo | o que é |
|---|---|
| `index.html` | a política de privacidade, em português |

Publicado por GitHub Pages em
<https://leonardo2606.github.io/bolo-nas-alturas/>.

Para atualizar, edite e dê push na `main`: o Pages republica sozinho em um ou dois
minutos.
